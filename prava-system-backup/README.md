# نظام التقديم والتوظيف العسكري - سيرفر برافو (PRAVA)

نظام متكامل لإدارة التقديمات والاختبارات والتوظيف لسيرفر برافو، يشمل:
- التقديم على القطاعات العسكرية (الشرطة، المباحث، مكافحة المخدرات، الطوارئ، الحرس الوطني، الدفاع الجوي، أمن المنشآت وغيرها).
- اختبارات القبول الإلكترونية وتصحيحها وحساب النسب آلياً.
- لوحة تحكم إدارية متقدمة للمالك والضباط والمسؤولين.
- ربط الويب هوك (Discord Webhook) المخصص لإرسال إشعارات التوظيف لكبار الضباط.
- نظام التعرف على الجهاز والدخول السريع بنقرة واحدة (Quick 1-Click Login & Auto-Login).
- تخصيص كامل للرسائل وشروط التقديم وفتح/إغلاق القطاعات.

---

## 🚀 طريقة التشغيل على جهازك الشخصي:

### 1. المتطلبات الأساسية:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
- محرر الأكواد (مثل VS Code).

### 2. تثبيت الحزم:
افتح موجه الأوامر (Terminal / CMD) في مجلد المشروع ونفّذ:
```bash
npm install
```

### 3. تشغيل المشروع في وضع التطوير:
```bash
npm run dev
```

افتح المتصفح وتوجه إلى:
```
http://localhost:3000
```

### 4. بناء المشروع للإنتاج (Production):
```bash
npm run build
npm start
```

## 📁 هيكلية المشروع:
- `src/` : كود الواجهة الأمامية والمكونات (React + Tailwind CSS + Lucide Icons).
- `server.ts` : الخادم الخلفي (Express API + Vite Middleware) لإدارة التقديمات والمستخدمين والويب هوك.
- `data/db.json` : قاعدة البيانات المحلية لبيانات السيرفر والمستخدمين والتقديمات.
- `index.html` : الصفحة الرئيسية ونقاط الدخول.
